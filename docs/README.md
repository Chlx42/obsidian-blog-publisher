## screenshot-panel.png

宽度 720 以上（README 里按 720 显示，留出 2x 余量），PNG。

要在一张图里同时出现的东西——这三样是文字讲不清、看一眼就懂的：

1. **按状态分组的文章列表**：至少各有一篇「可发布」「草稿」「需检查」。
   「需检查」那篇要能看到具体缺哪个字段，这是校验器的直观证据。
2. **实时日志**：同步或预览跑到一半的状态，日志里有几行输出。
   重点是让人看到日志在 Obsidian 里面，不用切终端。
3. **状态栏**：底部的运行状态和端口。

## 拍摄建议

- 用默认主题，深色浅色都行，别用重度自定义主题——看的人要能对应到自己的界面。
- vault 里放几篇标题是正常中文的文章，避免出现真实私人笔记。
- 面板宽度拉到能完整显示文章标题和右侧按钮，不要出现文字截断。
- 如果想放 GIF：录同步的完整一次，从点击到日志出现哨兵行结果，控制在 10 秒内。
  文件名用 `screenshot-panel.gif`，同时更新 README 里的引用。
