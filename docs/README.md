## 拍摄建议

- 用默认主题，深色浅色都行，别用重度自定义主题——看的人要能对应到自己的界面。
- vault 里放几篇标题是正常中文的文章，避免出现真实私人笔记。
- 面板宽度拉到能完整显示文章标题和右侧按钮，不要出现文字截断。
